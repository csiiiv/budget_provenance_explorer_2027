# Explorer web app

This Vite and React app builds static pages from
`index.html` (FMR), `nia.html` (NIA landing), `nia-provenance.html`,
`nia-titles.html`, `nia-documents.html`, `nia_map.html`, `dpwh.html`, and `about.html`. See the
[root README](../README.md) for setup, data exports, and browser checks.
